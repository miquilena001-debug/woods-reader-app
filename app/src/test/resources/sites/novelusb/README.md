# Fixtures de NovelUSB

Plantillas HTML reales recuperadas de capturas históricas de Wayback Machine (2023-04-16 / 2023-07-20) correspondientes a la novela `almighty-daughter-runs-the-world-novel`.
Se despojaron las barras de herramientas inyectadas por Wayback Machine y se normalizaron los enlaces al dominio original `novelusb.com`.
El cuerpo de los capítulos fue recortado a unos pocos párrafos manteniendo íntegro el marcado HTML, clases y estructura del contenedor `#chr-content`.
